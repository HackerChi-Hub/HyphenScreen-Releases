# HyphenScreen — 黒粉録画

[简体中文](README.md) · [繁體中文](README.zh-TW.md) · [English](README.en.md) · **日本語**

**画面収録から編集、書き出しまでを一つのデスクトップアプリで。** HyphenTech の HyphenScreen は、ソフトウェアの使い方、製品デモ、解説動画の制作を支援します。画面・カメラ・音声の収録に、マルチトラック編集、字幕、AI 編集支援を組み合わせています。

## ダウンロード

[インストーラーとリリースノート](https://github.com/HackerChi-Hub/HyphenScreen-Releases/releases) · [各 OS の提供バージョンとチェックサム](README.md#下载)

現在はプレビュー版です。各 OS の提供バージョンはダウンロード表をご確認ください。バージョンが古い OS のパッケージには、新しい機能がまだ含まれません。0.4.29 以降に追加した機能は三つの OS で同じソースからビルドしていますが、実機での確認は今のところ macOS のみです。インストーラーは公開、製品のソースリポジトリは非公開です。アプリ内の自動更新はありません。

## 主な機能

| 作業 | できること |
|---|---|
| 収録 | 画面やウィンドウ、マイク、システム音声、カメラを収録。録画設定をプリセットとして保存。範囲指定は macOS と Windows に対応。 |
| マルチトラック | 複数の動画と音声をまとめて読み込み。動画トラック数に固定上限はありません。上の表示トラックが下の映像を覆い、音声はミックスされます。 |
| 細かな編集 | クリップの移動・分割・複製・削除、端のドラッグによるトリミングと元の範囲の復元。Shift で微調整、ハンドルにフォーカスして矢印キーでフレーム調整。 |
| トラック整理 | 名前変更、順序変更、映像の非表示、音声のミュート、ロック。映像表示と音声ミュートは独立しています。 |
| 確認 | 全画面プレビュー（F で開始、Esc で終了）。トランスポートは自動で消えます。プレビュー解像度はフル / 3/4 / 1/2 / 1/3 / 1/4 から選べ、重いプロジェクトでも滑らかに再生。書き出しは常にフル解像度です。 |
| 波形 | タイムラインの波形は画面に見えている範囲だけを、デバイスピクセル単位で描画します。拡大するほど粗くなるのではなく細かくなり、最小で 1 本あたり 4 ミリ秒です。 |
| カメラと画面 | ピクチャーインピクチャー、左右／上下分割、カメラ全画面、背景設定、枠線とグラデーションのパルス。録画画面の縦横比を維持。 |
| 字幕と装飾 | ローカル文字起こし、字幕の手動編集、スタイル、タイトル、注釈、ズーム、分類されたビジュアルテンプレート。 |
| 音声 | 個別の音量、音声のトリミング、音声処理、会話に合わせた BGM ダッキング。ニューラル音声分離は現在 macOS のみ。 |
| AI 支援 | 設定済みのローカルモデル、または対応する Codex ログイン連携を利用。ツールとテンプレートで編集を支援します。結果はプレビューで確認してください。 |
| 仕上げ | MP4／GIF に書き出し、無音・黒画面・字幕のはみ出しなどをチェック。 |

扱える規模は端末、素材、エフェクトによって変わります。動画レイヤーは画面全体の置き換えであり、透明レイヤーの同時合成とは異なります。

## 基本の流れ

1. 収録するか、動画と音声をまとめて読み込みます。
2. 主映像の上に動画トラックを追加し、補足映像の位置と長さを調整します。
3. 字幕を直し、声と BGM の音量を整えて全体を再生確認します。
4. 書き出した動画を確認してから公開します。

## 動作環境とデータ

- macOS 13 以降、Apple シリコン。ローカル証明書で署名、Apple 公証は未実施。
- Windows 10／11 x64、D3D11 ハードウェア動画デコード対応 GPU。インストーラーは未署名。
- Linux x86_64、glibc 2.35 以降、Vulkan、デスクトップに対応する portal。AppImage には FUSE 2 が必要です。
- 収録・編集・書き出しはローカルで実行します。AI チャット利用時は、会話と関連するプロジェクトのテキストが選択したモデルサービスへ送信されます。匿名の利用統計はアプリのメニューで無効にできます。
- 必要な第三者ライセンス文書はアプリに同梱しています。
