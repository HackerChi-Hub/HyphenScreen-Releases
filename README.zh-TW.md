## 主要功能

- **同步錄製：** 螢幕、視窗、麥克風、系統聲音與攝影機；macOS 和 Windows 支援框選區域。常用設定可存成錄製配置。
- **多素材與多軌：** 一次匯入多個影片和音訊；影片軌道沒有固定數量上限，上方可見畫面覆蓋下方，聲音則疊加混音。可重新命名、排序、隱藏、靜音及鎖定轨道。
- **精細剪輯：** 拖動片段位置與左右邊緣，裁切或恢復原始內容；Shift 拖動微調，把手取得焦點後用方向鍵逐格調整。支援分割、複製及刪除。
- **攝影機與版面：** 子母畫面、左右或上下分割、攝影機全螢幕、背景處理、邊框與漸層脈衝；外框內的錄屏維持原始比例。
- **字幕與視覺：** 本機轉寫、手動修改字幕、多種字幕樣式、標題、標註、縮放與分類視覺範本。
- **預覽與檢視：** 全螢幕預覽（F 進入、Esc 離開），播放條自動淡出；預覽解析度可選完整、3/4、1/2、1/3、1/4，複雜專案播放更流暢，匯出一律使用完整解析度。
- **高解析度波形：** 時間軸波形只繪製畫面上看得見的那一段，並以裝置像素取樣，放得越大越清楚，最細每根柱代表 4 毫秒。
- **聲音處理：** 逐段音量、音訊裁切、人聲處理與背景音樂避讓；神經網路人聲隔離目前僅 macOS 提供。
- **AI 輔助：** 連接已設定的本機模型，或使用支援的 Codex 登入整合；透過工具與範本協助精剪、字幕及效果設定，產出仍需預覽確認。
- **輸出：** 匯出 MP4 或 GIF，並檢查成片的無聲、黑畫面、字幕越界等問題。

軌道數量不設固定上限，實際承載能力取決於裝置、素材與效果。影片軌道目前採整幅畫面覆蓋，不代表透明圖層混合合成。

## 快速開始

1. 錄製一段內容，或批次匯入影片與音訊。
2. 在主錄屏上方加入影片軌道，安排補充畫面，拖動邊緣微調長度。
3. 修改字幕、平衡口播和背景音樂，完整預覽時間線。
4. 匯出並檢查成片後再發布。

## 系統與資料

- macOS 13 以上、Apple 晶片；本機憑證簽署，尚未經 Apple 公證。
- Windows 10／11 x64、支援 D3D11 硬體解碼的顯示卡；安裝程式未簽署。
- Linux x86_64、glibc 2.35 以上、Vulkan 與對應桌面 portal；AppImage 需要 FUSE 2。
- 錄製、剪輯和匯出在本機執行。使用 AI 聊天時，對話及相關工程文字會傳送到所選模型服務；匿名使用統計可在軟體選單關閉。
- 安裝套件保留必要的第三方授權文件。
