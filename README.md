## 下载

登录有权限的 GitHub 账号，进入 [发行页面](https://github.com/HackerChi-Hub/HyphenScreen-Releases/releases) 下载 DMG。Apple 芯片 Mac 使用 `arm64` 安装包，将其中的“黑粉录屏 HyphenScreen.app”拖入“应用程序”。

安装包附带 `SHA256SUMS.txt` 与 `release-manifest.json`，用于核实文件完整性、源码提交和签名状态。初版采用本地黑粉科技代码签名证书，没有 Apple Developer ID 公证。

基础代码源自 OpenScreen，原版 MIT 许可与版权致谢随应用保留。软件功能范围以对应发行说明为准。
