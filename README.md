### 三种制作方式

1. **录完就剪**：录制屏幕与摄像头，裁掉废段、调整缩放、加字幕和音乐，再导出。
2. **少录一点，完整表达**：只录开头和必要操作，其余用图片、独立动画、视频素材和已有的 TTS 音频编排。
3. **让 AI 辅助编辑**：连接自己的模型，说明要压缩停顿、删除重复、调整字幕或生成动画，再预览核实。

软件本身可免费下载使用；云端 AI 订阅、API 与本地模型服务的条件由所选服务决定。录制和工程保存在本机，主动使用云端 AI 时会发送该次请求需要的对话和工程信息；本地模型的对应推理可留在电脑上。匿名设备计数可在设置中关闭。

### 常见问题

- **要注册黑粉录屏账号吗？** 不需要。使用云端模型时连接你自己的订阅或 API。
- **1.2.0 打开旧工程会怎样？** 第一次打开时自动转换成新格式（动画逐帧数据改存本机，工程文件大幅变小），并在原文件旁保留 `.pre-v10.bak` 备份。新格式工程旧版本打不开。
- **怎样更新？** 从应用菜单检查新版本，或到本页下载最新包覆盖安装。每个平台只保留最新公开版本。
- **安装被系统拦下？** macOS 包未做苹果公证，Windows 包未做代码签名。具体安装步骤和 SHA-256 校验见下方。
- **导出的视频有标识吗？** 有，1.4.0 起成片和 GIF 右下角带一个小的「黑粉科技」标志，随画面明暗自动换色，不能关闭；预览时不显示。
- **所有功能三平台都有吗？** 主要剪辑与动画能力跨平台；人声隔离、自动敏感文字识别和成片文字回读目前仅 macOS。Windows／Linux 包已经构建检查，桌面交互继续实机核验。

> 1.4.1 新增与修复：macOS 录制音频实时反馈、抠像画面／遮罩同步，以及安卓 USB 摄像头检测、统一前后镜头选择和四方向旋转。手机接入需要安卓 12 及以上、USB 调试授权与本机连接工具；小米 13 的真实 1080p／30 帧预览、90° 旋转及短录制的暂停／恢复／保存已核验；长时录制、旋转后录制和跨平台实机验证仍待完成。实机验证范围见仓库进度记录，手机功能于 1.4.1 加入。

### 多轨剪辑与整洁时间线

![多视频轨、独立音频与片段效果演示](screenshots/multitrack-0432.png)

批量导入视频与音频，视频轨数不设固定上限，上层可见画面覆盖下层，音频叠加混音。支持分割、移动、拖边裁切／恢复源内容、逐帧微调、标记和转场。常用操作放在分类右键菜单中。

标注、叠加效果和动画合为可展开的「视觉」分组，支持混合框选、批量删除与一次撤销。无素材的轨道自动隐藏；有内容但被隐藏、停用或静音的轨道仍保留。波形按可见区间与设备像素绘制，分段后仍按源时间取样。

A／B 选择和刀片，J／K／L 播放，I／O 入出点，M 标记，方向键逐帧；滚轮平移、组合键加滚轮缩放。复杂工程可降低预览分辨率，导出始终用完整分辨率。

### 平滑缩放与预览中直接调整

录制后根据鼠标停留与操作位置推荐缩放，支持平滑过渡、鼠标跟随或固定焦点。暂停时直接点选画面、摄像头、字幕和适用的标注／模板，拖动位置或调整大小。屏幕画面保持原比例，外框不拉伸内容；选择控件限制在预览区域，弹窗保持可操作。

## 安装

- **macOS（Apple 芯片）**：打开 DMG，把「黑粉录屏 HyphenScreen.app」拖进「应用程序」。安装包用黑粉科技本机证书签名、**没有做苹果公证**，首次打开会被拦下：在「应用程序」里右键点图标选「打开」，或先执行
  ```bash
  xattr -dr com.apple.quarantine "/Applications/黑粉录屏 HyphenScreen.app"
  ```
- **Windows 10/11 x64**：运行安装程序，可自选安装目录。**未做代码签名**，SmartScreen 会提示，点「更多信息 → 仍要运行」。
- **Linux x64**：AppImage 需要 FUSE 2（Arch `fuse2`、Debian/Ubuntu `libfuse2`），`chmod +x` 后直接运行；deb 与 pacman 已声明依赖（Vulkan 驱动、`xdg-desktop-portal` 及桌面对应后端、ALSA、libgomp）。基线为 glibc 2.35。

录屏需要系统授权：macOS 在「系统设置 → 隐私与安全性 → 屏幕录制」里勾选；Linux 的录屏全部经 xdg-desktop-portal，需要装上桌面对应的后端（`-gnome`、`-kde`、`-wlr` 等）。
